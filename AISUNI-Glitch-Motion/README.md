# AISUNI / GLITCH-MOTION

Herramienta de animación generativa que extiende el flujo de AISUNI / GLITCH-CODE: permite importar una imagen ya procesada o crear la distorsión desde cero, controlar su evolución temporal y exportar animaciones. Incluye modos de movimiento, timeline, variaciones, semilla reproducible y exportación MP4, GIF y fotogramas PNG.

- Versión de la aplicación: 1.0
- Archivo principal: `index.html`
- Dependencias externas: Tailwind CSS 3.4.17, mp4-muxer 5.1.3, gif.js 0.2.0, Inter y JetBrains Mono desde CDN.
- Procesamiento y generación: en el navegador mediante Canvas y JavaScript; no requiere backend. Las imágenes cargadas se procesan localmente. La codificación MP4/GIF se realiza en el navegador con las bibliotecas externas indicadas.
- App relacionada: [AISUNI / GLITCH-CODE](../AISUNI-Glitch-Code/)
