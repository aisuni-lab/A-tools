1. Qué contiene el paquete

ArchivoFunción
index.htmlLa herramienta completa: interfaz, CSS, JavaScript y generación de fragmentos de demo. Este es el archivo fuente editable y ejecutable.
INSTALACION.htmlEste instructivo. Ábrelo en el navegador; puedes imprimirlo o guardarlo como PDF.
README.mdResumen técnico, límites y estructura del código.
.nojekyllArchivo vacío para publicar directamente en GitHub Pages.

Descomprime el ZIP. Para probar sin hosting, abre index.html en un navegador moderno. La demo, los archivos propios, las mezclas y los PNG funcionan sin conexión. GIPHY requiere internet y una clave API; si el navegador restringe llamadas desde un archivo local, publica la herramienta por HTTPS.

No necesitas Node.js, npm, PHP, base de datos ni un proceso de compilación. El editor se ejecuta en el dispositivo del visitante. Las imágenes propias no se suben a un servidor.

2. Instalar en IONOS

Necesitas un plan de hosting con acceso al espacio web por administrador de archivos o SFTP. Si solo tienes un constructor de páginas que no permite subir HTML independiente, usa un espacio de hosting compatible o GitHub Pages.

  1. Entra en tu cuenta de IONOS y selecciona el contrato de hosting asociado al dominio.
  2. Abre el administrador de archivos del espacio web —puede aparecer como WebspaceExplorer— o conéctate por SFTP usando los datos del panel de tu contrato.
  3. Localiza la carpeta a la que apunta tu dominio. Dentro, crea una carpeta nueva llamada aisuni-mix. Así mantienes tu sitio existente intacto.
  4. Sube index.html e INSTALACION.html a esa carpeta. Sube los archivos descomprimidos, no solo el ZIP. El README es opcional.
  5. Abre https://tudominio.com/aisuni-mix/. Si no carga automáticamente, prueba https://tudominio.com/aisuni-mix/index.html.
  6. Comprueba que el dominio tiene HTTPS habilitado. Si prefieres un subdominio como mix.tudominio.com, asígnalo a esta carpeta desde la configuración del dominio y activa su certificado.
  7. Prueba Remezclar, importa un PNG y exporta una composición. Después conecta GIPHY como se explica abajo.

Los nombres de menú y la carpeta raíz dependen del contrato. Esta es una ruta general de publicación estática; no se ha accedido a tu panel IONOS. Ayuda de hosting de IONOS.

3. Instalar en GitHub Pages

  1. Inicia sesión en GitHub y crea un repositorio, por ejemplo aisuni-mix. Para la ruta más sencilla, usa un repositorio público. El código será visible para otras personas; no incluyas claves.
  2. En el repositorio, usa Add file → Upload files. Sube index.html, INSTALACION.html, README.md y, si lo tienes visible, .nojekyll directamente en la raíz. No los dejes dentro de otra carpeta.
  3. Confirma la carga con Commit changes en la rama main.
  4. Abre Settings → Pages. En Build and deployment → Source, selecciona Deploy from a branch.
  5. Selecciona la rama main, la carpeta /(root) y pulsa Save.
  6. Espera a que GitHub termine la publicación. Copia la dirección que muestre Pages; normalmente tendrá la forma https://TUUSUARIO.github.io/aisuni-mix/.
  7. Abre el enlace y realiza la misma prueba: remezclar, importar y exportar PNG.

No hace falta configurar GitHub Actions. Si no aparece Pages, revisa los permisos del repositorio y las opciones de tu cuenta. Instrucciones oficiales de publicación por rama.

4. Activar los stickers aleatorios de GIPHY

  1. Entra en GIPHY Developers y crea una cuenta o inicia sesión.
  2. Crea una aplicación con acceso a la API para web y copia la clave asignada.
  3. En Aisuni-Mix, abre Fragmentos → GIPHY → Conectar GIPHY.
  4. Pega tu clave y pulsa Guardar conexión. Marca Recordar en este navegador solo si quieres conservarla en ese dispositivo.
  5. Elige 12, 24 o 48 y pulsa Cargar stickers al azar. Cada solicitud usa el endpoint aleatorio de stickers. La herramienta mantiene los recursos existentes y añade el lote recibido.
  6. Para añadir una pieza concreta, pega el enlace de su página de GIPHY y pulsa Añadir.
La clave no viene incluida. La API oficial la exige. Sin ella puedes trabajar con la demo y tus archivos, pero no obtener lotes aleatorios de GIPHY. No se ha validado una descarga real con una clave del usuario.

La herramienta pide la versión estática del sticker y comprueba su canal alfa. Omite fotogramas vacíos, recursos sin transparencia real y duplicados; por eso un lote puede terminar con menos piezas. Utiliza una llamada API por intento: una clave beta puede agotar su cuota al pedir varios lotes grandes. La documentación consultada indica 100 llamadas por hora para claves beta; comprueba tu cuota vigente en el panel.

Dos acciones distintas: Cargar stickers al azar obtiene nuevos recursos de internet. Remezclar composición cambia la distribución de las piezas cargadas y no hace llamadas a GIPHY.

La clave permanece en memoria o en el almacenamiento local de ese navegador si lo elegiste; no se exporta en los proyectos. Cada visitante conecta su propia clave. Una integración pública para muchos usuarios requiere acordar con GIPHY las condiciones de producción y de uso/almacenamiento de sus recursos; la API no concede automáticamente permisos para reutilización comercial. La exportación y el guardado son acciones del usuario: usa material cuyos permisos cubran tu proyecto.

Referencias: Endpoint Random · Claves, cuotas y prácticas de integración.

5. Flujo de trabajo

  1. Forma guía: escribe texto, selecciona una forma o carga una imagen. La guía dirige las posiciones y nunca recorta los fragmentos. Para JPG o imágenes sin transparencia, selecciona zonas oscuras o claras y ajusta el umbral. Los SVG deben ser autocontenidos.
  2. Fragmentos: carga varios archivos a la vez o arrástralos al lienzo. Se admiten SVG, PNG, JPG/JPEG, WEBP y GIF. Los GIF se congelan al importarse; los de GIPHY usan su rendition estática. JPG mantiene su fondo rectangular.
  3. Colección: clic en una miniatura para activar o excluir esa pieza. Clic derecho para ajustar su frecuencia y consultar el origen, cuando existe.
  4. Composición: densidad es la cantidad objetivo; tamaño y variación controlan la escala; piezas grandes añade acentos; ángulo y giro aleatorio controlan orientación. Separación y superposición regulan proximidad de centros, sin simulación física exacta.
  5. Semilla: con los mismos recursos, ajustes y guía, la misma semilla reproduce la misma distribución en ese entorno. Las fuentes del sistema pueden cambiar entre dispositivos.
  6. Edición manual: selecciona una pieza en el lienzo, arrástrala, cambia su escala o giro y bloquéala. Las piezas bloqueadas mantienen su posición al remezclar. Eliminar un recurso o desactivarlo elimina también sus piezas de la mezcla.
  7. Variaciones: genera cuatro propuestas o guarda un estado manual. Haz clic en una miniatura para recuperar composición, recursos y ajustes. Se conservan hasta 16 estados.
  8. Fondo: color, transparencia, imagen a sangre o gradiente multipunto. Puedes añadir y quitar puntos y mover cada uno con X e Y.
  9. Movimiento: animación de entrada por gravedad, centro o aparición; opción de remezcla periódica con transición. La animación se previsualiza; esta versión exporta PNG estático, no vídeo ni GIF animado.
  10. Guardar: descarga un .json con recursos y variaciones. Para retomarlo, abre Lienzo y proyecto → Abrir proyecto. No hay guardado automático: guarda antes de cerrar la pestaña.
  11. Exportar: descarga PNG, hasta 4096 píxeles por lado, con el fondo que elegiste. Siempre exporta la composición final, no una fase intermedia de la animación.

Atajos: Ctrl/⌘ Z deshacer; Ctrl/⌘ Shift Z rehacer; Escape deseleccionar; Suprimir elimina la pieza seleccionada. Los atajos no interceptan la escritura en campos.

6. Solución de problemas

SituaciónQué hacer
El hosting muestra 404Comprueba carpeta, nombre exacto index.html y ruta del dominio. En GitHub revisa rama main y /(root).
La página no se actualizaVuelve a subir index.html y fuerza la recarga. En GitHub espera al nuevo despliegue.
GIPHY rechaza la solicitudRevisa clave, permisos y cuota. Un error 429 indica límite de solicitudes. Espera o usa un lote menor.
Lote incompletoAlgunos resultados pueden repetirse, no tener alfa útil o fallar al cargar. Se muestra la cantidad realmente importada.
Una URL no importaUsa el enlace completo de la página del sticker. Si su servidor bloquea lectura de píxeles, descarga el recurso permitido y cárgalo como archivo local.
La guía parece un rectánguloEn una imagen opaca selecciona Zonas oscuras o Zonas claras; ajusta el umbral. Para texto con fondo transparente, usa Transparencia.
La mezcla pierde la formaReduce dispersión y tamaño; aumenta moderadamente la densidad. El contorno es aproximado por diseño.
Demasiada superposiciónAumenta separación, reduce superposición o baja tamaño y densidad. No es un empaquetador de colisiones exactas.
Lentitud o memoria altaReduce resolución del lienzo, cantidad de recursos y estados guardados. Pausa animación. Las importaciones de fragmentos se reducen a 700 px en su lado mayor.

7. Actualizar y editar el código

Haz una copia de index.html, edítala en un editor de texto y reemplaza el archivo publicado. Todo el CSS está en <style> y la lógica en <script>. No hay librerías externas que instalar. Conserva el nombre y la ruta del instructivo si quieres mantener el enlace de Ayuda.

La herramienta usa funciones estándar de navegador. Se verificaron sintaxis y flujos del motor con Canvas: semilla reproducible, bloqueo, deshacer/rehacer, lectura de guía opaca, validación de alfa, guardado/recuperación y PNG transparente. La vista web no se sometió a QA interactivo en un navegador real en este entorno; la compatibilidad con cada navegador y el flujo real de GIPHY deberán comprobarse con tu clave.
