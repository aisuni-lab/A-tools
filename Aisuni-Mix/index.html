Tu laboratorio de mezclas.

1. Escribe una palabra, elige una forma o carga una imagen como guía invisible.

2. Importa tus fragmentos o conecta GIPHY. Las piezas conservan su silueta y nunca se recortan contra la guía.

3. Ajusta densidad, escala y dispersión. Pulsa Remezclar o genera cuatro variaciones. Arrastra cualquier pieza y bloquéala para conservarla.

4. Guarda el proyecto para seguir editándolo, o exporta un PNG. Con fondo transparente podrás componerlo en otras aplicaciones.

Atajos: Ctrl/⌘ Z deshacer · Ctrl/⌘ Shift Z rehacer · Escape deseleccionar · Suprimir borrar pieza.

Los GIF locales se congelan al importarlos. GIPHY utiliza su versión estática y exige una clave propia. Las descargas conservan referencias de autoría en el proyecto; comprueba los permisos de uso de cada recurso.

Instrucciones: IONOS y GitHub Pages ↗

Conectar GIPHY

Crea una aplicación API en GIPHY Developers ↗ y pega tu clave.

La clave se envía directamente a GIPHY. No se incluye al guardar proyectos ni al descargar la herramienta. Los límites de tu cuenta pueden reducir el lote disponible.

Exportar composición

PNG con el fondo elegido. La exportación captura la composición final, sin controles.

Para continuar editando usa Guardar, que descarga un proyecto .json con sus recursos.
