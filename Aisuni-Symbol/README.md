# Aisuni-Symbol

Herramienta generativa para explorar variaciones del símbolo AISUNI mediante cambios de proporciones geométricas y color. Permite ajustar radios concéntricos y colores por capa, usar armonías y presets, comparar legibilidad en distintos tamaños y exportar el resultado como SVG o PNG de alta resolución.

- Archivo principal: `index.html`
- Dependencias externas: Tailwind CSS y fuentes Inter / JetBrains Mono desde CDN.
- Generación y exportación: en el navegador; no requiere backend.

[Probar Aisuni-Symbol](https://aisuni-lab.github.io/A-tools/Aisuni-Symbol/)
