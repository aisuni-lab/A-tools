# Aisuni-Image-Synth

Herramienta generativa para reinterpretar imágenes y crear composiciones gráficas con patrones híbridos, variaciones de semilla y controles de color y textura. Permite exportar resultados en PNG de hasta 4800 × 6000 px y como SVG editable.

- Versión de la aplicación: 2.0
- Archivo principal: `index.html`
- Dependencias externas: Tailwind CSS 3.4.17 y fuentes Inter / JetBrains Mono desde Google Fonts.
- Procesamiento de imágenes y generación: en el navegador; no requiere backend.

[Probar Aisuni-Image-Synth](https://aisuni-lab.github.io/A-tools/Aisuni-Image-Synth/)
