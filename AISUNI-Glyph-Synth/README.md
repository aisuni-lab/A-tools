# AISUNI Glyph Synth

Herramienta generativa que combina 12 símbolos AISUNI en composiciones de glifos con variaciones de semilla, color y capas. Incluye un loop animado de mitosis, vista de cinco fases, mosaico de nueve variaciones y exportación de imágenes PNG y video WebM.

- Versión de la aplicación: 1.6
- Archivo principal: `index.html`
- Dependencias externas: Tailwind CSS 3.4.17 y fuentes Inter / JetBrains Mono desde Google Fonts.
- Procesamiento y generación: en el navegador; no requiere backend.

[Probar AISUNI Glyph Synth](https://aisuni-lab.github.io/A-tools/AISUNI-Glyph-Synth/)
