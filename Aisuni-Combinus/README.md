# Aisuni-Combinus

Fragmenta imágenes y combina el collage con una pila reordenable de efectos.

- **Versión:** 1.0
- **Probar:** https://aisuni-lab.github.io/A-tools/Aisuni-Combinus/

Abre `index.html` en un navegador moderno o sirve esta carpeta con un servidor estático. La herramienta procesa archivos localmente. PDF.js está incluido bajo Apache-2.0; consulta `vendor/PDFJS-LICENSE.txt`.
