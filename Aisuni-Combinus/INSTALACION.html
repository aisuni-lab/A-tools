Aisuni-Combinus.

Collage, azar y efectos en el navegador.
Versión 1.0 · Guía de instalación y uso

Sube la carpeta completa. index.html necesita app.js, effects.js, los dos CSS, demo.jpg y vendor/. Mantén sus nombres y estructura. No necesitas instalar Node, bases de datos ni claves API.

Instalar en IONOS

  1. Descomprime Aisuni-Combinus_Fuentes.zip.
  2. En el espacio web de tu hosting, usa el administrador de archivos o SFTP. Crea una carpeta combinus dentro del directorio público asignado a tu dominio.
  3. Sube todo el contenido descomprimido. index.html debe quedar directamente dentro de esa carpeta, acompañado por los archivos JS/CSS y vendor/.
  4. Activa el certificado SSL y abre https://tu-dominio.com/combinus/, sustituyendo el dominio por el tuyo. Si instalas en la raíz pública, abre directamente tu dominio.
  5. Verifica la demo, carga una imagen y PDF, añade efectos, descarga un PNG y graba un vídeo corto.

Los nombres de menús y la carpeta pública dependen del plan de IONOS. Necesitas alojamiento de archivos HTML/JS; un bloque de código del constructor puede no permitir todos los recursos.

Conserva .htaccess para los tipos MIME de módulos JS y WASM en Apache. Si ya tienes reglas propias, integra las dos directivas sin sobrescribir tus reglas. Si aparece un error 500, comprueba que el hosting permita esas directivas.

Instalar en GitHub Pages

  1. Crea un repositorio. Para la ruta gratuita habitual, utiliza uno público: también serán visibles los archivos fuente que subas.
  2. Sube el contenido a la raíz, incluyendo toda la carpeta vendor/. GitHub Desktop o Git facilitan subir muchos archivos.
  3. En Settings → Pages, elige Deploy from a branch, rama main, carpeta / (root), y guarda.
  4. Espera a que termine y abre la dirección indicada por GitHub Pages.
  5. Comprueba demo, PDF, PNG y vídeo. Conserva .nojekyll; GitHub ignora .htaccess.

No subas tus proyectos o imágenes personales al repositorio: no son necesarios para publicar el editor.

Crear un collage

  1. Carga una imagen o PDF y elige su página.
  2. Selecciona Recto, Polígono, Rasgado, Tiras, Orgánico o Mixto. Los cortes tienen irregularidades sutiles.
  3. Usa texto, forma, imagen o modo Libre como guía. La guía orienta posiciones y no recorta piezas.
  4. Ajusta Tamaños, giro, separación y superposición. Remezclar collage conserva cortes; Volver a fragmentar crea cortes nuevos y reemplaza las piezas bloqueadas.
  5. En Editar piezas, arrastra, escala, gira o bloquea fragmentos. En Resultado, revisa los efectos.

Combinar efectos

Abre Efectos, elige uno y pulsa ＋. El orden va de arriba hacia abajo. Usa las flechas o arrastra las tarjetas para cambiarlo; selecciona una tarjeta para editarla.

  • Casilla: activa o desactiva ese efecto.
  • Mezcla %: interpola entre su entrada y salida.
  • ⧉ / ×: duplica o elimina.
  • Azar / Fijo: permite remezclar parámetros o los conserva.
  • Semilla de efectos: reproduce una combinación desde un número.
  • Remezclar efectos: genera otra combinación y respeta efectos fijados.
  • Aplicar pila: desactiva todos los efectos, también al exportar.

Hay ocho efectos: Grano, Papel, Color, Mapa de color, Ondulación, RGB, Mosaico y Movimiento global. Se aplican al conjunto, incluido el fondo. Grano y papel varían la luminosidad sin añadir tinte.

El bloqueo de una pieza conserva su posición al remezclar el collage. Fijo conserva parámetros de un efecto al remezclar efectos: son independientes.

Movimiento y exportación

Movimiento anima los fragmentos. Ondulación y Movimiento global también responden a reproducción y al control de tiempo. La preview usa resolución reducida; PNG usa el tamaño solicitado.

  • PNG 1×–8×: composición final de fragmentos, efectos activos en fase inicial y fondo elegido. Admite transparencia.
  • Vídeo: grabación en tiempo real, sin audio, MP4 o WebM según compatibilidad. Mantén la pestaña visible; ocultarla cancela.
  • El vídeo usa fondo opaco. Muchos efectos pueden bajar la fluidez: prueba 720 px y 24 FPS.
  • 8× son 64 veces más píxeles. Límite preventivo: 48 megapíxeles con efectos u 80 sin efectos, sujeto a la memoria real. No se reduce automáticamente el archivo. Reduce el lienzo o el multiplicador si se rechaza.
  • El origen se rasteriza hasta 2000 px. Ampliar salida no inventa detalles nuevos.

Guardar y recuperar

Guardar descarga un JSON con medios, cortes, posiciones, efectos y variaciones. Guarda antes de cerrar: no hay guardado automático. Abrir proyecto acepta Combinus y Aisuni-Collage 1.x. Los acabados antiguos se convierten a Grano y Papel. Conserva una copia del proyecto original.

Resolver problemas

  • PDF no abre: usa HTTPS o servidor local; no file://. Comprueba que vendor/ esté completa.
  • Faltan estilos/demo: revisa rutas y mayúsculas de nombres.
  • Versión antigua: recarga sin caché tras subir archivos nuevos.
  • PNG grande: reduce resolución o multiplicador.
  • Vídeo no disponible: usa un navegador actualizado que ofrezca MediaRecorder y captura del lienzo.
