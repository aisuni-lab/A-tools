# Aisuni-Re-Trace-Geometrica

Herramienta generativa que reinterpreta imágenes como composiciones geométricas planas mediante bloques, polígonos, líneas y puntos. Permite ajustar el modo de segmentación, densidad, escala, diversidad geométrica, paleta, semilla y animación del trazado; incluye demos, variaciones y una tira de composiciones aisladas. Exporta imágenes PNG/JPG y gráficos SVG.

- Versión de la aplicación: 1.0
- Archivo principal: `index.html`
- Dependencias externas: Tailwind CSS 3.4.17 y las fuentes Inter / JetBrains Mono desde CDN.
- Procesamiento y generación: en el navegador mediante Canvas y SVG; no requiere backend. Las imágenes cargadas se procesan localmente.
