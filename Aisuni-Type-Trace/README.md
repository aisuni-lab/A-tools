# Aisuni-Type-Trace

Herramienta de tipografía generativa que reinterpreta una imagen mediante bloques, polígonos, líneas y puntos dispuestos alrededor de texto editable. Incluye controles de composición, paletas, semilla aleatoria, historial deshacer/rehacer, animación del trazado, variaciones y una tira para coleccionar composiciones tipográficas aisladas. Exporta la composición como PNG, JPG o SVG, y la tira como SVG.

- Versión de la aplicación: 1.0
- Archivo principal: `index.html`
- Dependencias externas: Tailwind CSS 3.4.17 y las fuentes Inter / JetBrains Mono desde CDN.
- Procesamiento y generación: en el navegador mediante Canvas y SVG; no requiere backend. Las imágenes cargadas se procesan localmente.
