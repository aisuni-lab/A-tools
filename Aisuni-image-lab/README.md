# Aisuni Image Lab

Static source copied from the published tool at https://grafitat.com/aisuni/ (version 2.3, 2026-11-07).

Open `index.html` in a modern browser or serve this folder with a local static web server. Image files are processed client-side. The embedded site token was intentionally omitted; importing images directly from URLs requires the original site's PHP proxy endpoint and is not available in this standalone copy. Use local image uploads instead.
