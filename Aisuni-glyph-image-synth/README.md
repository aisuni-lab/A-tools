# Aisuni-glyph-image-synth

Herramienta generativa que reinterpreta imágenes mediante una retícula adaptativa de glifos AISUNI. Permite ajustar símbolos, escala, capas tonales, tintas, paletas y superficie; incluye comparación con la imagen original y seis variaciones. Exporta composiciones como PNG o JPG de hasta 8K y como SVG con objetos vectoriales expandidos.

- Versión de la aplicación: 1.6
- Archivo principal: `index.html`
- Dependencias externas: Tailwind CSS 3.4.17 y fuentes Inter / JetBrains Mono desde Google Fonts.
- Procesamiento de imágenes y generación: en el navegador; no requiere backend.
