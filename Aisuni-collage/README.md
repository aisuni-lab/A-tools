# Aisuni Collage

Fragmenta imágenes o páginas de PDF y reorganiza las piezas en collages exportables.

- **Versión:** 1.1
- **Probar:** https://aisuni-lab.github.io/A-tools/Aisuni-collage/

Abre `index.html` en un navegador moderno o sirve esta carpeta con un servidor estático local. La herramienta procesa los archivos en el navegador. PDF.js está incluido bajo Apache-2.0; consulta `vendor/PDFJS-LICENSE.txt`.
