# Aisuni-Pattern-Synth-01

Generador algorítmico de texturas y patrones gráficos. Permite explorar arquetipos visuales, paletas de color, capas y variaciones por semilla; incluye composición guiada por imagen y exportación PNG de hasta 6000 × 6000 px.

- Versión de la aplicación: 2.0
- Archivo principal: `index.html`
- Dependencias externas: Tailwind CSS 3.4.17 y fuentes Inter / JetBrains Mono desde Google Fonts.
- Procesamiento de imágenes y generación de patrones: en el navegador; no requiere backend.

[Probar Aisuni-Pattern-Synth-01](https://aisuni-lab.github.io/A-tools/Aisuni-Pattern-Synth-01/)
