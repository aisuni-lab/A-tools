# AISUNI / GLITCH-CODE

Herramienta creativa de databending que transforma imágenes y archivos SVG mediante corrupción de bytes, inyección hexadecimal, fracturas de bloques, desfases de scanlines y efectos cromáticos. Incluye modos algorítmicos, controles de intensidad y escala, semilla reproducible, variaciones, zoom e historial para deshacer y rehacer. Exporta los resultados como PNG, JPG o SVG.

- Versión de la aplicación: 1.0
- Archivo principal: `index.html`
- Dependencias externas: Tailwind CSS 3.4.17 y las fuentes Inter / JetBrains Mono desde CDN.
- Procesamiento y generación: en el navegador mediante Canvas, manipulación de bytes JPEG y edición de XML SVG; no requiere backend. Los archivos cargados se procesan localmente.
