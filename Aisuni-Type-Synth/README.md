# Aisuni-Type-Synth

Generador tipográfico cinético que transforma palabras o glifos en composiciones de cintas, vórtices y fracturas geométricas. Incluye presets, paletas, variaciones por semilla y mosaico de nueve versiones; exporta a PNG de alta resolución o SVG editable.

- Versión de la aplicación: 6.0
- Archivo principal: `index.html`
- Dependencias externas: Tailwind CSS y fuentes Inter / JetBrains Mono desde Google Fonts.
- Generación gráfica: en el navegador; no requiere backend.

[Probar Aisuni-Type-Synth](https://aisuni-lab.github.io/A-tools/Aisuni-Type-Synth/)
