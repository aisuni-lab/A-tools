# Aisuni-Pattern-Synth-02

Sintetizador de patrones gráficos con píxeles fusionados. Combina matrices Bayer, dithering, módulos geométricos, paletas y composición guiada por imagen para generar texturas continuas y exportarlas como PNG.

- Versión de la aplicación: 1.2
- Archivo principal: `index.html`
- Dependencias externas: Tailwind CSS 3.4.17 y fuentes Inter / JetBrains Mono desde Google Fonts.
- Generación y análisis de imágenes: en el navegador; no requiere backend.
