# Aisuni-Trazos

Analiza bordes, contrastes, colores o la silueta principal de una imagen para generar trazos vectoriales cerrados, con variaciones controlables y exportación en PNG, JPG o SVG.

- **Probar:** https://aisuni-lab.github.io/A-tools/Aisuni-Trazos/
- **Fuente:** https://www.grafitat.com/trazos/

Abre `index.html` en un navegador moderno o publica esta carpeta en un servidor estático. La imagen de entrada se procesa localmente; no se carga a un servidor. Se incluyen las dependencias D3 utilizadas por el modo de silueta.
